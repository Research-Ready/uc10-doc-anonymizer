Architectuur & Modellen Details

• spaCy NLP Modellen: nl_core_news_lg (3.7.0) en en_core_web_lg (3.7.1) ingebouwd in Docker container (poort 5010).

• Document Parser: Docling CPU container (poort 5001) met pypdfium2 backend.

• Entiteiten Register: Neo4j 5.x Graph Database (poort 7687 / 7474) voor consistente globale pseudoniemen over meerdere documenten.

• Evaluatie & Prompt Flows: ChainForge Web UI (poort 8000), direct te verbinden met lokale Ollama modellen (zoals Llama 3, Qwen, DeepSeek op poort 11434).

• Privacy Garantie: Geen cloud LLM API calls. Geen verbinding met externe servers tijdens de verwerking.
