# keys/

One `<name>.<ext>.entity_map.json` per anonymized document: which original value became which label.

**These files are personal data.** Together with the anonymized document they undo the anonymization.
They are kept here, apart from `output/`, so `output/` can be shared without them.
Don't share this folder. Delete a key when the project no longer needs to trace labels back.
Everything here except this README is kept out of git.
